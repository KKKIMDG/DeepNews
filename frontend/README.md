# DeepNews Analyzer

사용자가 보고 있는 뉴스 기사(네이버 뉴스와 일반 언론사 사이트)의 본문을 브라우저에서 추출해 로컬 백엔드로 보내고, 키워드·AI 요약·광고성 판단·유사 기사 추천을 사이드 패널과 기사 위 팝업으로 보여 주는 MV3 확장 프로그램입니다.

## 구조

- `src/content/extract-article.js`: 페이지 DOM **복사본**에서 제목·본문·발행 시각을 추출합니다(네이버 선택자 우선, 그 외 로컬 번들 Readability 0.6.0).
- `src/content/content-script.js`: 본문 키워드 하이라이트(DOM API만 사용, `innerHTML` 없음)와 closed shadow root 팝업.
- `src/background/service-worker.js`: 탭별 분석 상태(`chrome.storage.session`), 백엔드 호출, 메시지 발신자 검증. 현재 탭의 상태를 `storage.local`로 복사해 패널이 그립니다.
- `src/background/api-client.js`: 모든 API 호출(`http://127.0.0.1:8000/api/v1`).
- `src/panel/*`: 사이드 패널과 `privacy.html`(개인정보처리방침 초안). 로그아웃 상태에서는 캐릭터 인사와 2단계 회원가입(계정 → 관심 분야·키워드)을, 로그인하면 분석·맞춤·설정 탭을 보여 줍니다. `mascot.js`는 캐릭터 SVG와 타이핑 효과이며, 애니메이션은 설정 탭에서 끌 수 있습니다.
- `src/shared/constants.js`: 메시지 타입과 스토리지 키.

## 실행

1. 백엔드(또는 GPU 서버로 가는 SSH 터널)를 `127.0.0.1:8000`에 띄웁니다.
2. `chrome://extensions` → 개발자 모드 → `압축해제된 확장 프로그램을 로드`에서 이 폴더를 선택합니다. 코드를 바꾼 뒤에는 새로고침합니다.
3. 기사 페이지에서 확장 아이콘으로 사이드 패널을 열고 로그인한 뒤 **현재 기사 분석**을 누릅니다. 처음 분석하는 사이트는 그때 접근 권한을 묻습니다.

## 동작 원칙

- 페이지 방문만으로는 아무것도 보내지 않습니다. 분석 버튼을 누를 때만 그 origin 권한을 요청하고 본문을 보냅니다. 허용한 사이트는 패널의 "사이트 권한"에서 해제할 수 있습니다.
- 서버는 기사 URL에 접속하지 않습니다. 분석에는 로그인이 필요하며, 결과는 다른 사용자와 공유되는 데이터입니다.
- 다른 사용자가 먼저 분석한 결과에는 안내와 **신고** 버튼이 붙습니다. 서로 다른 사용자 신고 3건이 쌓이면 서버가 결과를 지우고, 다음 분석 때 새로 분석합니다.
- 본문은 100~100,000자, 제목은 최대 500자입니다. PDF·브라우저 내부 페이지·유료벽 뒤 본문은 지원하지 않습니다.
- 하이라이트는 네이버 본문 선택자 → 흔한 기사 본문 선택자 → 텍스트가 가장 많은 블록 순으로 본문 영역을 찾습니다.
- 서버 오류: 401이면 로그인을 지우고, 403(비밀번호 확인 실패)은 로그인을 유지하며, 409(빅카인즈 기사와 본문 불일치)·429(요청 제한)·503(모델 준비 안 됨, 분석 대기열 가득 참)은 서버 메시지를 그대로 보여 줍니다.
