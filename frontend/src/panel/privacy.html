개인정보 처리방침

DeepNews Analyzer 확장 프로그램과 분석 서버가 처리하는 정보를 설명합니다.

이 문서는 검토 전 초안입니다. 담당자와 소속 기관의 검토를 거쳐 확정되기 전까지 내용이 바뀔 수 있습니다.

1. 수집하는 정보

  • 계정 정보: 이메일 주소, 비밀번호(원문은 저장하지 않고 scrypt로 해시한 값만 저장)
  • 로그인 세션: 로그인 토큰의 해시값(SHA-256)과 만료 시각
  • 읽은 기사 기록: 분석한 기사, 읽은 시각, 읽은 횟수
  • 관심사 설정: 가입할 때나 이후에 고른 관심 분야, 직접 추가한 관심 키워드와 제외 키워드
  • 추천 설정: 광고성 기사 숨김 기준값
  • 기사 신고: 분석 결과를 신고한 기록과 선택 입력한 신고 사유

2. 기사 본문과 분석 결과

확장 프로그램은 사용자가 현재 기사 분석 버튼을 눌렀을 때만 그 페이지의 주소, 제목, 본문, 발행일을 분석 서버로 보냅니다. 버튼을 누르지 않은 페이지의 내용은 읽거나 보내지 않습니다.

보낸 기사 본문과 키워드, 요약, 광고성 판단 결과는 다른 사용자도 함께 쓰는 공용 기사 데이터로 저장됩니다. 같은 기사를 다른 사용자가 분석하면 저장된 결과를 보여 주며, 결과가 기사와 다르면 신고할 수 있습니다.

3. 이용 목적

  • 회원 식별과 로그인 유지
  • 기사 키워드 추출, 요약, 광고성 판단 제공
  • 읽은 기사, 관심 분야, 관심 키워드를 바탕으로 한 기사 추천

4. 보관 기간

  • 로그인 세션은 발급 후 30일이 지나면 만료됩니다. 로그아웃하거나 비밀번호를 바꾸면 그 전에 폐기됩니다.
  • 계정 정보, 읽은 기사 기록, 관심사 설정은 회원 탈퇴 시까지 보관합니다.
  • 공용 기사 데이터(기사 본문, 키워드, 요약, 광고성 판단 결과)는 탈퇴 후에도 남습니다.

5. 열람, 내보내기, 삭제

  • 패널의 읽은 기사와 관심 분야·관심 키워드에서 기록을 확인하고 하나씩 지우거나 바꿀 수 있습니다.
  • 내 데이터 내보내기로 계정 정보, 키워드 설정, 읽은 기사 기록을 JSON 파일로 받을 수 있습니다.
  • 회원 탈퇴를 하면 계정, 세션, 읽은 기사 기록, 관심사 설정이 즉시 삭제됩니다.

6. 제3자 제공과 처리 위탁

수집한 개인정보를 제3자에게 제공하거나 외부 업체에 처리를 맡기지 않습니다.

7. 저장 위치와 보호 조치

  • 서버 위치: 연구용 서버(대학 내)
  • 비밀번호와 로그인 토큰은 해시값으로만 저장합니다.
  • 확장 프로그램은 로그인 토큰을 브라우저의 확장 프로그램 저장소에 보관하며, 웹 페이지에는 전달하지 않습니다.
  • 기사 본문을 읽는 권한은 사용자가 허용한 사이트에만 적용되며, 패널의 사이트 권한에서 언제든 해제할 수 있습니다.
